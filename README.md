# cs-dark-midia

Arquivos de mídia do canal CS Dark (vídeos verticais sobre Counter-Strike 2), servidos pelo GitHub Pages para agendamento de posts.

- Vídeos: `v/<tema>.mp4`
- Link direto: `https://lucas-oliveira-viana.github.io/cs-dark-midia/v/<tema>.mp4`

Fotos de jogadores e logos de times pertencem aos respectivos titulares e aparecem com crédito, em uso editorial. Os créditos estão no fim de cada vídeo.
